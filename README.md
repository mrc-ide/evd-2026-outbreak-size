# Estimation of the size of the Ebola outbreak caused by Bundibugyo virus in the Democratic Republic of the Congo

Code underpinning results of Bundibugyo virus disease (BVD) outbreak size analysis. We use two methods, backcalculation from deaths (method 1) and geographical spread (method 2) to estimate the size of the outbreak.

Initial reports can be found:
